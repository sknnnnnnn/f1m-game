# R50 — ปรับภาพและเมนูตามภาพผู้ใช้

## สิ่งที่แก้

1. นำเมนู R49 รวมเข้าลิงก์เกมหลักเดิม เพื่อให้ R48 ตรวจอัปเดตได้ เก็บ preview49 เป็นกระจกสำหรับผู้ที่ติดตั้งจากตัวทดลอง
2. เปิดด้วยหลอดโหลด มีรถ F1 มุมข้างและล้อหมุน รถขยับตาม milestone ของโมเดล/การประกอบรถ/พิต/วัสดุ/worker ไม่สร้างเปอร์เซ็นต์จากเวลาเดา
3. โรงรถใหม่: ผนังเป็นแผง แสงด้านข้าง พื้นและเงาสัมผัส ตู้เครื่องมือ/จออยู่ด้านหลัง ไม่มีเส้นไฟเพดานพาดหน้ากล้องและป้ายยักษ์
4. หน้าหลักเน้นรถ ย่อหัวข้อและปุ่ม ตัดคำโปรยยาว การ์ดสนามใช้รูปเส้นทางจากศูนย์กลางสนามที่เล่นจริง
5. ยกเลิกช่างหกคนเดินวนในเมนู ใช้ช่างสองคนยืนตรวจแท็บเล็ตในตำแหน่งงานเฉพาะหน้า inspect/pre ขาอยู่กับพื้นและขยับมือ/ศีรษะเล็กน้อย ไม่อ้างว่าเพิ่มแอนิเมชันเดินสมจริงหรือซ่อมรถเต็มรูปแบบ
6. เอากล่องข้อความลมดูดออก แสดงเส้นลมบริเวณขอบจอเมื่อเร็วกว่า 140 กม./ชม. และเพิ่มความเข้มตาม draft จริง ไม่บังกลางถนน รองรับ reduced motion และหยุดเมื่อพักเกม/เข้าพิต/ออกจากเรซ/ธงเตือน
7. ย่อ HUD และ DRS เอาประโยคแผนขับออกจาก live HUD ข้อมูลละเอียดอยู่แผงคุมทีม/อันดับ วิทยุทั่วไปยังเก็บประวัติ แต่แสดงเฉพาะข้อความสำคัญในภาพสด
8. เปลี่ยนสนามแล้วเริ่มต่อให้โดยไม่ต้องกดลงสนามซ้ำ
9. ปุ่มอัปเดตเด่นบนหัวเมนูเมื่อมี worker ใหม่พร้อมติดตั้ง ยังต้องกดเองและพักเรซก่อน

## การตรวจ

- build และ PWA static/service-worker tests ผ่าน แคชแยก scope และไม่สลับรุ่นกลางเรซอัตโนมัติ
- tests/interface50.mjs: ความเร็ว/ลมดูดจริงเป็นตัวคุมเอฟเฟกต์, gating, ไม่มี readout box, reduced motion และหลอดโหลด
- tests/tow45.mjs: แรงดูดและแมพเดิม + canvas overlay ที่ไม่มีข้อความ
- tests/menu49.mjs: session/stage/laps/save/load/validation และ rig ขาไม่ยืดในท่ายืนทำงาน
- race-story34 และ watch24 (fixture Bahrain), grid33 ของ Bahrain/Shanghai/Suzuka ผ่าน
- Cloud browser: อัปเดต R49 → R50 ด้วยปุ่มจริง, เปิดโรงรถ desktop/390×780, เปลี่ยน Shanghai → Bahrain หนึ่งรอบแล้วโหลดเข้าแข่งอัตโนมัติ, กล้อง FPS และ HUD ไม่มีข้อความลมดูดด้านซ้ายบน
- ไฟล์เผยแพร่ตรวจ Git blob SHA เทียบ dist ทุกไฟล์ ไม่ใช่เพียงตรวจชื่อ build

## ข้อจำกัด

เครื่อง browser ทดสอบใช้ CPU fallback ภาพมี aliasing และ FPS ต่ำ จึงไม่ใช้เป็นหลักฐานภาพ WebGL/ความลื่นบน Android เครื่องจริง ไม่ได้ทดสอบเรซยาวทุกสภาพอากาศในรุ่น UI นี้

R50 ไม่เปลี่ยน physics/AI/แรงดูด/DRS/ERS หรือโมเดลรถและระบบพิตระหว่างเรซ จุดมุ่งหมายของรุ่นนี้คือเมนู ภาพนำเสนอ HUD และการอัปเดต
