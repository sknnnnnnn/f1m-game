# Race story — วิทยุ กล้อง และสรุปผล

Build `0ce632be9c8bcb9a` ต่อจาก `932ad21a4fbc03fd` บน branch develop/f1m-engine-1.0

## ใช้งาน

- ระหว่างแข่ง: ข้อความวิทยุของรถที่เลือกแสดงสั้น ๆ พร้อมเสียงสัญญาณเมื่อเปิดเสียงเกม ข้อความเร่งด่วน เช่น ธงและยางเสีย มีลำดับก่อนข่าวทั่วไป ไม่มีเสียงพูดสังเคราะห์
- กล้อง → Cinema: ติดตามรถที่เลือกต่อไป แต่ตอบรับเหตุการณ์แซงจริงได้ก่อนมุมปกติครบช่วงค้าง และปรับคำบรรยายให้ตรงสถานการณ์แม้ใช้มุมเดิม
- ตั้งค่า → ผลการแข่งขัน → แตะชื่อนักขับ: ดูสรุป P เริ่ม/ปัจจุบัน จำนวนแซงและถูกแซง การเปลี่ยนอันดับบนสนาม/จากวงจรพิท เวลาพิทรวม คิวที่รวมอยู่แล้ว โทษเวลา เวลาต่อรอบและเหตุการณ์ล่าสุด
- หน้าจบเรซ: แสดงสรุปรถที่เลือก พร้อมปุ่มเปิดรายละเอียดทุกคัน

## พฤติกรรม

วิทยุกรองรถอื่นที่ไม่เกี่ยวข้อง ไม่แสดงซ้ำทุกเฟรม แสดงครั้งละข้อความนานไม่เกิน 6.5 วินาที มี cooldown ตามประเภท เก็บประวัติสูงสุด 16 รายการและ key สูงสุด 96 รายการ ซ่อน/ไม่เตือนใหม่ขณะพักหรือรีเพลย์ ล้างข้อมูลเมื่อรีเซ็ตหรือเปลี่ยนรถ ธงเขียวแทนข้อจำกัดเดิมได้ทันที ข้อความใช้หลักฐานจาก radio, moments, pitEvents, tyre health และคู่แข่งข้างหน้าที่ส่งมาจริง

การขึ้น/เสียตำแหน่งในไทม์ไลน์อิงเหตุการณ์ที่ engine ยืนยัน ไม่สร้างจุดแซงหรือเวลาที่ไม่มีข้อมูล และไม่รับประกันว่าจะเก็บทุกเหตุการณ์ไว้จนจบเรซเพราะ telemetry เป็นรายการที่มีขอบเขต

เวลารอบเทียบกับรอบเร็วที่สุดที่บันทึกไว้ รวมผลจากสตาร์ต การจราจร พิท และธง จึงไม่กล่าวว่าเวลาที่ช้าลงทั้งหมดเกิดจากสาเหตุใดสาเหตุหนึ่ง คิวพิทเป็นส่วนที่รวมในเวลาพิท ไม่บวกซ้ำ

## ตรวจสอบ

- npm test: 37 งานผ่าน รวม checksum แกน/โมเดลเดิม 20 ไฟล์ และ worker parity
- Fixtures ใหม่ทั้ง Bahrain, Shanghai และ Suzuka: กรองวิทยุ คุมซ้ำ จัดลำดับธง พัก/รีเพลย์/รีเซ็ต ป้องกันชื่อ HTML คำนวณเวลารอบและคิวพิท ไม่สร้างเหตุการณ์ซ้ำ กล้องรับจังหวะแซงโดยไม่เปลี่ยนรถที่ติดตาม
- อ่าน presentation จาก simulation จริงทั้งสามสนาม แล้วเทียบ state รถทุกคันก่อน/หลังว่าไม่เปลี่ยน
- กราฟเสียง reuse oscillator/gain เดิม เสียงเตือนเคารพ mute และไม่สร้าง node ต่อข้อความ
- build และ PWA tests ผ่าน รวมตัวอัปเดตที่ดาวน์โหลดไฟล์แยกตามเวอร์ชันและไม่แทนเกมระหว่างเรซอัตโนมัติ

ไม่มีการเปลี่ยนระบบขับ AI เส้นทาง reference ความเร็ว ยาง แรงเครื่อง จำนวนรถ หรือกราฟิกของสนาม ชุดแข่ง 6 คันและฟีลขับจากรุ่นก่อนยังเป็นฐานเดิม การเพิ่มครั้งนี้อยู่ในชั้นการแสดงผลและเสียง

ข้อจำกัด: ยังไม่ได้ยืนยันการฟัง/ตำแหน่ง UI/FPS บน Android หลังแพตช์ และ fixtures ไม่แทนการดูภาพจบเรซจริงบนอุปกรณ์ ภาพกล้องยังอยู่ภายใต้ข้อจำกัด renderer เดิม
