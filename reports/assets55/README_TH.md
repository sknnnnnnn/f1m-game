# F1M RACE 55 — โหลดและใช้ Asset ซ้ำ

เปิดเล่น: https://sknnnnnnn.github.io/f1m-game/preview55/

## สิ่งที่เปลี่ยน

1. **ไฟล์ไม่เปลี่ยนไม่ดาวน์โหลดใหม่ในระบบแคชใหม่:** โมเดล GLB, engine/CPU/rig/hand และไอคอนเก็บด้วย SHA-256 ของเนื้อไฟล์ ใช้ซ้ำข้ามรุ่นและ preview บน origin เดียวกัน ไฟล์ที่ hash เปลี่ยนต้องโหลดและตรวจ hash ใหม่ก่อนติดตั้ง ไม่เปิดอัปเดตระหว่างแข่งโดยอัตโนมัติ
2. **โหลดพร้อมกันสูงสุดสี่งาน:** ลดการเปิดดาวน์โหลด/ตรวจ hash พร้อมกันทั้งชุดบนมือถือ งาน hash เกิดตอนติดตั้ง/ซ่อมแคช ไม่เกิดทุกเฟรม
3. **อ่านและแปลง GLB รถเพียงครั้งเดียวต่อหน้า:** โรงรถและสนามแชร์ต้นฉบับที่แปลงแล้ว แต่ clone โหนดและใช้ material แยกกันก่อนทำสี รูปทรงที่ไม่เปลี่ยนแชร์ได้ ไม่ใช้โมเดล base64 หรือ localStorage ก้อนใหญ่
4. **ฉากนิ่งใช้เมทริกซ์เดิม:** ตำแหน่งถนน พร็อพ อาคาร และห้องโรงรถที่นิ่งคำนวณครั้งเดียว หลีกเลี่ยงการ compose/เดินกิ่ง static ซ้ำ ธงและชิงช้าสวรรค์ยังทำงาน พร้อมกล้องหลบสิ่งกีดขวางผ่าน visibility เช่นเดิม
5. **เริ่มเรซใหม่ใช้ฉากเดิม:** โครงสร้างการ initialize สนามแบบ promise เดียวและ reset ผ่าน worker เดิมถูกคงไว้ R54 สร้างสนามครั้งเดียวต่อหน้าอยู่แล้ว ไม่ได้โหลดโมเดลจากเครือข่ายทุกเฟรม รุ่นนี้ลดงานซ้ำที่ยังเหลืออยู่

## หลักฐาน

- `ASSETS_AND_STATIC.json`: อ่าน/parse รถจาก GLB จริงพร้อมกันสองผู้ใช้เหลือ 1 ครั้ง; เปลี่ยนสีและตำแหน่ง clone แยกได้; ลบแท็ก model หลังโหลดแล้วยังใช้แคชเดิม; โหลดล้มเหลวแล้ว retry ได้
- `CACHE.json`: ไฟล์ทั้งหมด 18 รายการ; ติดตั้งข้าม scope ครั้งที่สองใช้ immutable เดิม 9 รายการ โดย GLB และ engine ดาวน์โหลดใหม่ 0 ครั้ง; shell/โมเดลเปิดออฟไลน์; hash เปลี่ยนต้องโหลดใหม่; เนื้อไฟล์ผิด hash ทำให้อัปเดตติดตั้งไม่ผ่าน
- `SCENERY_shanghai.json`: 219 โหนดล็อกตำแหน่ง; ตรวจ mesh ฉากนิ่ง 190 ตัว; ธง 7 ผืนยังขยับ
- `SCENERY_suzuka.json`: 218 โหนดล็อกตำแหน่ง; ตรวจ mesh ฉากนิ่ง 186 ตัว; ธง 7 ผืนและชิงช้าสวรรค์ยังขยับ
- `SCENERY_bahrain.json`: 823 โหนดล็อกตำแหน่ง; ตรวจ mesh ฉากนิ่ง 718 ตัว
- ทั้งสามสนามมี local transform compose ของ mesh ฉากนิ่ง 0 ครั้งระหว่าง 12 เฟรมที่ตรวจ และ world matrices/geometry ตรงเดิมทุกตัว
- ทดสอบเดิมที่เกี่ยวข้อง: release54, menu49, interface50, static-batch, PWA static ผ่าน; ไม่รันการแข่งขันเต็มซ้ำเพราะไม่เปลี่ยนฟิสิกส์หรือ AI

## วิธีใช้งาน

เปิดลิงก์ R55 แล้วให้การติดตั้งแคชครั้งแรกเสร็จ รุ่นนี้เริ่มแคชตามเนื้อไฟล์ครั้งแรก จึงยังมีโหลดเริ่มต้นหนึ่งครั้ง ไม่ต้องล้างข้อมูลเว็บไซต์ รุ่นถัดไปใช้ไฟล์เดิมจากแคชเมื่อเนื้อไฟล์ไม่เปลี่ยน การกลับเมนูและเริ่มใหม่ภายในหน้าเดิมใช้ฉาก/โมเดลที่เตรียมไว้แล้ว

หากปิดหน้า เว็บต้องสร้างฉากและส่งทรัพยากรเข้า GPU ใหม่เมื่อเปิดอีกครั้ง; Cache Storage เก็บไฟล์ ไม่เก็บ GPU scene ข้ามการปิดโปรเซส เบราว์เซอร์อาจล้างแคชเมื่อพื้นที่ไม่พอ และแคชไม่ข้าม origin/โหมดไม่ระบุตัวตน

## ข้อจำกัดที่ยังไม่ปิด

ไม่ได้ลดจำนวนสามเหลี่ยม ระยะมองเห็น DPR คุณภาพเงา หรือจำนวนรถ 22 คัน ยังต้องวาดฉากที่กล้องมองเห็น

คลิป R54 ของผู้ใช้แสดง 8–16 FPS และ simulation ประมาณ 42% ของเวลาจริง รุ่นนี้แก้ asset/cache/static transforms เท่านั้น ไม่ถือว่าแก้คอขวดฟิสิกส์หรือ GPU ครบ และยังไม่รับรอง 60 FPS/จอกระพริบบน Android ต้องวัดบนเครื่องจริง งานทดสอบเป็นการตรวจไฟล์จริงและข้อมูล Three.js; canvas ในการทดสอบ Node เป็น mock จึงไม่ใช่หลักฐานภาพ/GPU
