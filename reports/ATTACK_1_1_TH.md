# F1M Attack 1.1 — เร่งเต็ม เบรกหนัก และปรับภาพสามสนาม

Build `0b48ecee592c1915` ต่อจาก Mobile Fix commit d8ff9f7 บน develop/f1m-engine-1.0 ต้นฉบับและประวัติสำรองเดิมยังอยู่ ไม่มีการแก้ main และยังไม่มีการ push ไป GitHub สำเร็จ

## การขับ

- ปรับ preset เกมให้เกาะและเร่งแรงขึ้น: mu 2.7, ERS 300 kW / 8 MJ, pedal rate 16, steering rate 1.1 ไม่มีการเขียนค่าความเร็วหรือตำแหน่งรถโดยตรง ไม่แก้ frozen solver/controller หรือโมเดลเดิม
- เพิ่ม ABS ในตัวส่งคำสั่งจริง ใช้การลื่นของล้อที่ยังรับน้ำหนักเพื่อไม่ให้ล้อด้านในที่ลอย/เบาทำให้เบรกทั้งรถหาย ลดอาการล้อล็อกไถลยาว การเบรกเปียก/ยางสึก/โค้งยังขึ้นกับแรงเกาะจริง
- AI ขอแรงเร่งเต็มเมื่อมีระยะและแรงเกาะพอ หยุดส่ง feed-forward เบรกล่วงหน้าขณะความเร็วจริงยังต่ำกว่า envelope มากเกินไป และใช้ความสามารถเบรกใหม่วางจุดชะลอใกล้โค้งขึ้น คงการระวังคู่แข่ง Pit ธง และ Safety Car
- คุมความเร็วผ่านโค้งด้วย margin แยกจากแรงเกาะสำหรับออกตัว/หยุดรถ เพื่อไม่ให้เพิ่มกำลังแล้วพุ่งหลุดโค้ง
- DRS ตามคันหน้าไม่เกิน 3 วินาทีที่จุดตรวจ คงเงื่อนไขปิดเมื่อเบรก เลี้ยวแรง ธง และเข้า Pit
- Safety Car ใช้ preset แยกจากรถแข่ง เพื่อไม่รับแรงเร่ง/เบรกแบบ Attack ตามไปด้วย

## สนามทั้งสาม

- Shanghai: ผิวถนนเข้มมีร่องยางละเอียด หญ้าเป็นแถบ ตกแต่งสีแดง/ทอง ปรับวัสดุหลังคาและกระจก เพิ่ม pavilion/ป้ายริมทาง 9 จุด
- Suzuka: โทนหญ้าเขียวและป้ายฟ้า/ขาว ผิวถนนและกรวดใหม่ ปรับวัสดุอาคาร เพิ่ม pavilion/ป้าย 10 จุด
- Bahrain: โทนทรายอุ่นมีลายผิว สนามและกรวดใหม่ ป้ายแดง/ครีมและขอบเรืองแสงยามกลางคืน เพิ่ม pavilion/ป้าย 9 จุด
- รวมชิ้นส่วน static ตาม material ไม่เพิ่ม realtime light ไม่ลด resolution, โมเดล หรือระยะมองเห็น ถนน Pit และโครงสนามเดิมอยู่ครบ

## ผ่านแล้ว

- npm test: frozen checksum 20 ไฟล์, physics serial/worker parity, DRS, Championship, crew, bridge geometry, ABS/straight acceleration/braking, scene construction ของสามสนาม และ static triangles/UV preservation
- Acceptance integration: 6 คันวิ่งครบ 1 รอบ seed 7 ทุกสนาม ไม่มีรถ DNF ไม่มี race guard stop และไม่มี controller rejection (`ATTACK_ACCEPTANCE.json`)
- Pit: รถ 6 คันเข้าจุดหยุดของตัวเองครบทั้ง China/Suzuka ไม่มีมุมตัวรถรุกพื้นที่ทำงานของ bay อื่น ไม่มี rejection (`PIT_BAYS_*.json`)
- Safety Car ครบวงจรจน PARKED/กลับ GREEN ไม่มี rejection (`ATTACK_SAFETY.json`)
- Build และ PWA static/unit ผ่าน
- Remote browser เปิดและวาดกริดครบทั้งสามสนาม รวม Bahrain กลางคืน ตรวจภาพผิวถนน/พื้นและสถาปัตยกรรมด้วย CPU fallback แล้ว

## ยังไม่ยืนยัน

ยังไม่มี Android เครื่องจริงหรือ WebGL GPU ในเครื่องทดสอบ จึงไม่อ้าง 30/60 FPS หรือรับรองว่าหายกระตุกบนโทรศัพท์ ยังไม่ได้ทดสอบทุก seed, เรซ 4–5 รอบทั้งฤดูกาล, pit release/merge ทุกสถานการณ์ และการติดตั้ง/อัปเดต PWA บน Android จริง

รับเวอร์ชันใหม่: พักเกม → ตั้งค่า → ตรวจอัปเดต → อัปเดตพร้อมแล้ว แล้วเริ่มเรซใหม่ เซฟฟิสิกส์รุ่นก่อนอาจเข้ากันไม่ได้กับ preset ใหม่
