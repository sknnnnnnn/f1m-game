# แก้พิตหยุดปลายเลนและรอยต่อโมเดลเซอร์วิส

Build `b1da04136309c013` · GitHub Pages · source develop/f1m-engine-1.0

## พฤติกรรม

- รถชะลอหยุดที่ช่องเซอร์วิสตามฟิสิกส์ แล้วเร่งกลับสู่ความเร็วจำกัดประมาณ 80 กม./ชม. ไม่บังคับหยุดปลายพิตทุกครั้ง
- ตรวจช่องบนทางหลักก่อนรวมสนาม ถ้ามีรถขวางยังชะลอและรออย่างปลอดภัย พอช่องว่างเปิดจึงออกได้ ไม่มีเวลารอขั้นต่ำที่บังคับเพิ่ม
- คุมความเร็วจนพ้นเส้นออกพิตจริง แล้วส่งสถานะตำแหน่ง ความเร็ว ล้อ และเกียร์เดิมกลับให้ AI ขับต่อ ไม่มีการตั้งความเร็วเป็นศูนย์
- ตัวคุมคันเร่งในพิตแปลงแรงที่ต้องการเป็นคันเร่งจริง รวมแรงต้านอากาศ ไม่ใช้เพดานคันเร่งอย่างเดียว และยังคงเบรกเมื่อแผนขับถูกปฏิเสธ
- ทางออกพิต Shanghai/Suzuka เชื่อมตำแหน่ง แนวสัมผัส และความโค้งด้วยเส้น quintic 120 เมตร แทนโค้งสั้นที่มีความโค้งกระชาก พื้นถนนและรถใช้เส้นเดียวกัน
- โมเดลเซอร์วิสรับ matrix จากโมเดลรถที่แสดงอยู่โดยตรง รวมระดับพื้น มุมและสเกล แก้ความคลาดเคลื่อนจากการคำนวณตำแหน่งซ้ำและ offset สูง 4.5 ซม.
- รถยังชะลอตามทางเข้าช่องพิต/รถขวาง และหยุดระหว่างเซอร์วิส ความเร็ว HUD มาจากฟิสิกส์จริง

## ขอบเขตการตรวจ

รายงาน CONTINUITY ทั้งสามสนามใช้รถที่อินทิเกรตฟิสิกส์จริงตลอดรอบพิต และให้ fixture ส่งหลักฐานว่าช่างพร้อมปล่อยรถเท่านั้น ตรวจไม่หยุดเมื่อทางออกว่าง, จำกัดความเร็ว, ความเร็วต่อเนื่องที่เส้น, เร่งหลังออก และไม่มีการย้ายตำแหน่งรถ

MODEL_HANDOFF ใช้ไฟล์ GLB จริงกับ prepareCar ตรวจกรอบตำแหน่งล้อและปีกหลังว่าตรงกับโมเดลแข่ง ส่วน six-bay run ใช้รถหกคันเข้าช่องจริงและตรวจ footprint ทุกช่อง รายงานและ log อยู่ใน pit35/

การตรวจ scene graph และฟิสิกส์ยังไม่ใช่การดูแอนิเมชั่น WebGL บน Android จริง ต้องตรวจภาพต่อบนเครื่องผู้ใช้ ไม่มีข้อสรุปเรื่อง FPS หรือ GPU จากชุดทดสอบนี้

Frozen solver/controller, รถ GLB, การขับบนสนามหลัก, หกคันและคุณภาพกราฟิกคงเดิม การพยากรณ์เวลาพิตใช้เพดานความเร็วทางออกที่แก้แล้ว
