# F1M RACE 57 — Mobile vehicle model experiment

เปิดเล่น: https://sknnnnnnn.github.io/f1m-game/preview57/

## เปลี่ยนแนวทางตามคลิปอ้างอิง

รุ่นนี้เปลี่ยนแบบจำลองรถที่ใช้งานจริง ไม่ใช่เพียง cache หรือเร่งโค้ดให้ได้ผลเดิมทุกค่า

- **MOBILE57 four-wheel semi-implicit:** แบบจำลองแรงยางเชิงเส้นในช่วงเกาะถนน พร้อมขอบเขตแรงเสียดทานรวมสี่ล้อ แรงกดอากาศ การถ่ายน้ำหนักโดยใช้ความเร่งขั้นก่อน แรงต้านอากาศ แรงบิดเครื่องยนต์ เกียร์ พลังงาน ERS/regen ความร้อน การสึกและความเสียหายยาง ใช้การแก้ระบบตัวถัง 3×3 และจำกัด active friction circles ไม่เกินสี่รอบ แทน Newton เจ็ดตัวแปรที่วนหลายรอบ
- ตำแหน่งและทิศรถยังเกิดจากการอินทิเกรตความเร็ว/แรง ไม่มีการย้ายรถตามเส้นสนามเพื่อแต่งการแซง และไม่ได้เพิ่มกติกาให้คันนำผ่อนเพื่อให้รถหลังผ่าน
- ทำฟิสิกส์ภายใน **race worker เดิม** โดยตรง หยุดส่ง state/environment/ผลสี่ล้อไปกลับ physics workers เพิ่มสามตัว UI/render thread ยังแยกจากการจำลอง
- คง solver56/frozen/reference physics เพื่อใช้เทียบและ audit `runPhysicsBatch` ยังคง REFERENCE56 เป็นค่าเริ่มต้นสำหรับผู้เรียกชุดทดสอบเดิม ส่วน production race worker เรียก `mobileRuntime57` และ sequential Weekend2Race.advance เรียก MOBILE57
- กล้องหลักเริ่มเป็น **MANAGER** มุมเฉียงสูงและตามรถต่อเนื่อง หมุน/ซูมได้ ปุ่มกล้องเดิมยังอยู่ และไม่ได้ลด DPR เงา geometry หรือระยะมองเห็น
- แสดง **FPS · GPU/CPU** บน HUD เพื่อแยกว่ากำลังใช้ WebGL หรือ CPU fallback

### พิตพร้อมกัน 22 คัน

ใช้ fixture เดิม เริ่มใกล้ช่องพิตและเดินฟิสิกส์จริงหลังตั้งต้น ใช้ช่องร่วมทีม 11 ช่อง ไม่มี service ซ้อนทีม ไม่มี stop/rejection รถออกครบ 22: Shanghai 84.867 s, Suzuka 89.333 s, Bahrain 84.950 s การยืนยัน crew-clear เป็นข้อมูลจาก fixture ไม่ใช่การตรวจภาพช่างบน GPU

### พฤติกรรมรถและฝน

- ตรวจแรงไม่เกิน friction circle, โหลดไม่ติดลบ, energy อยู่ในช่วง, บัญชี ERS/regen, deterministic state/records และการปฏิเสธคำสั่งผิด 2,220 substeps
- ตัวทดสอบเบรกตรงจาก 300 km/h ถึงต่ำกว่า 4 km/h: แห้ง 2.817 s, น้ำ 3 mm 4.683 s เป็นค่าจากแบบจำลอง ไม่ใช่ข้อมูลสอบเทียบ F1 จริง
- รถ 22 คันพร้อมยาง I ฝน/น้ำเริ่มต้น 1.2 mm วิ่ง 30 วินาทีที่ Shanghai: ไม่มี off-track/stop/rejection น้ำสูงสุดที่ตรวจ ~2.006 mm
- กล้อง portrait/landscape 240 เฟรม + pit framing: ไม่เขียนสถานะฟิสิกส์และคง far distance 1,800 m
- reference audit เดิมยังผ่าน 20 pinned files + reference batch 6 คัน ×180 ticks exact parity; ผลนี้ยืนยัน reference เดิมเท่านั้น ไม่ได้อ้างว่า MOBILE57 ให้ผลตรงเดิม

### เวลา CPU บน host

เทียบแบบสลับ baseline/new ในโปรเซสเดียว ทั้งคู่ 22 คัน ×180 ticks (3 วินาทีจำลอง):

| งาน | Reference56 | MOBILE57 |
|---|---:|---:|
| ฟิสิกส์รวม | 2799.936 ms | 195.840 ms |
| จำลองรวม AI/control/commit | 4030.141 ms | 1433.118 ms |

ฟิสิกส์เร็วขึ้น ~14.30× และ simulation รวม ~2.81× ใน fixture นี้ ตัวเลข **ไม่ใช่ FPS บน Android** และไม่ได้รวม GPU หรือ IPC ของ parallel production รุ่นเดิม

## ข้อจำกัดและเกณฑ์ที่ยังไม่ผ่าน

นี่คือแบบจำลองเชิงประมาณสำหรับเกมผู้จัดการทีม การยึดเกาะ การตอบสนองเบรก/โค้ง และเวลาในสนามเปลี่ยนจาก reference56 ไม่มีการรับรองความแม่นระดับ simulation วิศวกรรม/CFD หรือการอนุรักษ์พลังงานกลแบบ solver เดิมทุกขั้น เก็บต้นฉบับไว้เพื่อเทียบและย้อนกลับ

การทดสอบไม่ยืนยัน 60 FPS หรือแก้จอกระพริบดำบนมือถือ การตรวจ GPU จริงยังทำไม่ได้ใน browser ทดสอบนี้ และเรายังไม่มีคลิป/รายงาน R57 จากมือถือผู้ใช้

เปิด R57 ให้เห็น footer RACE / 57 แล้วดู FPS พร้อมคำ GPU/CPU ระหว่างแข่ง ตัว CPU หมายถึงโปรแกรมกำลังวาดภาพด้วย CPU fallback; แคชพร้อมไม่สามารถใช้แทนหลักฐาน GPU/FPS ได้
