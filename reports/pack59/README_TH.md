# F1M R59 — รถรวมกลุ่ม / แซง / ลายรถ

เล่น: https://sknnnnnnn.github.io/f1m-game/preview59/

## ผลที่เปลี่ยน

- แคชท่าพวงมาลัย แขน เสื้อ และฝ่ามือร่วมระหว่างรถ 22 คัน แก้ IK ครั้งเดียวต่อ sample มุม ไม่แก้ซ้ำทุกคันทุกเฟรม Sample ห่าง 0.5 องศาของมุมเลี้ยวท่าคนขับ (คลาดเคลื่อนสูงสุด 0.25 องศา) ล้อที่สัมผัสถนนและฟิสิกส์ยังใช้มุมจริง
- ข้ามการอัปเดต world matrices ทั้งคันใน wing/driver เมื่ออยู่ใน race WebGL path แล้วให้ instancing อัปเดตหลังวางรถและแอนิเมชันครบ
- ไม่ส่งรถที่อยู่นอกมุมกล้องไปวาด โดยเผื่อขอบเขตตัวรถและเงาบนพื้นอย่างกว้าง รถกลับเข้าภาพใช้โมเดลเดิมทันที ไม่เปลี่ยนระยะมองเห็น 1,800 เมตร ไม่ลด mesh, DPR หรือแสงเงา
- ลายรถ 11 ทีม: แถบสีหลายชั้น แผงสีหลัก/รอง ตัวหนังสือ และลายเส้นบนตัวถัง ใช้ atlas 2048×1536 ภาพเดียวและ per-instance tile จึงไม่แตก material/texture draw call ตามจำนวนรถ
- เริ่มเบี่ยงแซงก่อนตามจี้จนต้องเบรก รักษาช่องที่ยึดไว้ระหว่าง braking duel เมื่อมีโอกาสทัน และใช้ ERS จากพลังงานที่มีจริง จังหวะ Shanghai ใช้เกณฑ์ต่างจาก Suzuka/Bahrain
- แก้การอ่านรอบล้อล็อกที่ทำให้เกียร์อัตโนมัติลดลงต่ำผิดจังหวะ ใช้ความเร็วกลิ้งอ้างอิงขณะเบรกในการเลือกเกียร์ ไม่เขียนทับความเร็วหรือเติมแรงขับ
- ส่งธงเหลืองเฉพาะจุดให้ AI/DRS ตามเขต caution เดิม 220 เมตร รถที่อยู่นอกเขตกลับมาแข่งได้ VSC/RED ยังเป็นทั้งสนาม รถในเขตยังต้องชะลอ/ห้ามแซง

## หลักฐาน

`STEERING.json`: actual GLB / 22 rigs / เทียบ transform และผิวจริง 176 คู่ที่ sample angles งานท่าคนขับบน host เร็วขึ้นประมาณ 28× เฉพาะส่วนนี้ ไม่ใช่ whole-frame speedup หรือ FPS มือถือ

`LIVERY.json`: actual GLB 22 คัน, atlas เดียว, 11 team tiles, สอง draw submissions สำหรับผิวตัวถังหลักสองรูปทรงที่ลงลาย และจำนวนสามเหลี่ยมเท่าเดิม ตรวจ shader injection / instance attributes; ไม่ใช่หลักฐาน GPU pixel rendering

`FRUSTUM.json`: fixture 22 คัน 11 คันอยู่นอกภาพ ข้ามเฉพาะกลุ่มนั้น เข้าเฟรมแล้วคืนโมเดลเดิม ไม่เปลี่ยน root visibility / far plane

`ACCEPTANCE.json` และ `AFTER_*.json`: เมนูจริง seed ปกติ 7 / 22 คัน / หนึ่งรอบต่อสนาม ทุกคันจบ ไม่มี stop, retire, controller rejection ตัวเลขการแซงเป็นการเปลี่ยนอันดับจากตำแหน่งจริง รวมการแซงคืน ไม่ใช่จำนวนคู่ดวลที่ไม่ซ้ำ

`BEFORE_shanghai.json`: R58 seed เดียวกัน ไม่มีการเปลี่ยนอันดับหลังวินาที 60 ใช้เทียบกับ R59 ไม่ใช้คะแนนออกตัวเป็นหลักฐานการแข่งช่วงท้าย

`FLAGS.json`, `PLANNER.json`: local/global flags, no-space, pit/recovery, คำสั่ง SAVE/CONSERVE/ABORT, พลังงานจำกัด และเกียร์ขณะล้อล็อก

ผ่าน targeted checks: actual car instancing, menu49, interface50, draft48 (ปรับ assertion ให้สอดคล้องกับ early pull-out), battles47, DRS Suzuka, pit model handoff, frozen engine-core 20 files / exact reference batch parity 6 คัน 180 ticks, worker transport, PWA, service worker และ build

## ข้อจำกัด

ยังไม่รับรอง 60 FPS บน Android งาน GPU ของรถที่เห็นพร้อมกันยังมีอยู่ การทดสอบ host ไม่แทนมือถือ และ cloud browser ไม่รองรับ WebGL ในสภาพแวดล้อมนี้ จึงยังต้องตรวจภาพลายรถ/เงาจริงจากอุปกรณ์

การแซงเพิ่มใน fixture บางช่วง แต่ไม่ได้รับรองว่าทุกทีม ทุกสนาม ทุก seed จะดวลตลอดเวลา โดยเฉพาะรถที่ทิ้งระยะไปแล้ว ไม่มีการชะลอผู้นำเพื่อรวมกลุ่ม ไม่เติมแบต ไม่เปลี่ยนตำแหน่งหรืออันดับด้วยสคริปต์
