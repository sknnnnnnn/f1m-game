# วิทยุใช้เสียงเตือนเท่านั้น

Build `51ebd4a8e57dec00`

นำระบบสังเคราะห์เสียงพูดออก รวมการพูดตอนเปิดเสียง ปุ่มเปิดเสียงพูด ปุ่มลองเสียง และการลดเสียงเครื่องขณะพูด ข้อความวิทยุและเสียงเตือน Web Audio เดิมคงอยู่ ใช้สวิตช์เสียงหลักควบคุม ไม่มีการเปลี่ยนการขับ ภาพ หรือฟิสิกส์

## รายงานเครื่องที่ผู้ใช้แนบ

รายงานของ build bacf02672a85af4c บน Android ขณะขับสนาม Shanghai กล้อง chase, WebGL HIGH, กระจกหลังปิด วัด painted FPS ประมาณ 40.23 ในหน้าต่างตัวอย่าง 180 ช่วงเฟรม (ไม่ใช่ benchmark เต็มเรซ) เฟรม median 25 ms, P95 41.8 ms; JS frame work median 15.4 ms, P95 21.5 ms; งานวาดฉาก median 9.65 ms และงานรถ 3.7 ms (P95 9 ms), ช่างพิต median 0 ms; errors ว่าง

งานถัดไปควรลด CPU/render submission และต้นทุนอัปเดตโมเดลรถ พร้อมตรวจ frame pacing บนจอรีเฟรชสูง ก่อนเพิ่มฉากหรือเอฟเฟกต์ใหม่ ตัวเลขนี้ยังไม่ใช่หลักฐาน 60 FPS และเทียบข้ามรายงานเป็นผล A/B โดยตรงไม่ได้

## ตรวจสอบ

ตรวจว่า source/bundle ไม่มี speech synthesis หรือปุ่มเสียงพูด build และ PWA/service worker ผ่าน ชุดทดสอบหลัก 47 งานผ่าน (exit 0) หลักฐานการเผยแพร่แยกใน RADIO_CHIME_DEPLOYMENT.json
