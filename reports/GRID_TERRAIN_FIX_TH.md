# แก้เจ้าหน้าที่ขาลากและพื้น Suzuka ตัดถนน

คงค่าฟิสิกส์ ฟีลขับ ความเร็ว ไลน์ เบรก คันเร่ง ยาง และรายละเอียดกราฟิกจาก ba525293537c4435 ทั้งหมด

- เจ้าหน้าที่: ก้าวตามความเร็วและทิศทางเคลื่อนที่จริง คำนวณจังหวะเท้าที่ 120 Hz แยกจาก FPS ภาพ เท้าลงนำตัวเพียงพอก่อนสลับขา จึงไม่ดึงสะโพกลงเพราะเท้าค้างไกลด้านหลัง
- Suzuka: กดจุดยอดพื้นภูมิประเทศรอบแนวถนนให้ต่ำกว่าถนนทั้งสามเหลี่ยม รวมทางลอดใต้สะพาน แทนการอิงเพียงความสูงที่ใกล้จุดยอดที่สุด ไม่เปลี่ยนเส้นทางหรือความสูงถนน

ตรวจแบบจำลองเจ้าหน้าที่ 18 คนตั้งแต่กริดถึงเดินออกครบ ที่ 15/30/60 FPS ทั้งสามสนาม: สะโพกขณะเดินสูงอย่างน้อย 0.80 เมตรในสเกลตัวละคร และความคลาดเคลื่อนความยาวหน้าแข้งต่ำกว่า 1e-12 เมตร (เกณฑ์ 0.02)

Raycast พื้นหญ้า Suzuka ที่ซ้าย/กลาง/ขวาของถนนทุกประมาณ 5.4 เมตร รวมบริเวณทางข้าม: พื้นสูงสุดยังต่ำกว่าถนน 1.469 เมตร

npm test (31 งาน), npm run build และ npm run test:pwa ผ่าน

ขอบเขตการยืนยัน: ทดสอบเรขาคณิตและท่าเคลื่อนไหวด้วย Three.js บน Node ยังไม่ได้ยืนยันภาพเคลื่อนไหวบน Android หลังแก้
