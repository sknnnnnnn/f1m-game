# Overtaking investigation 41 — ยังไม่ผ่าน / ไม่เผยแพร่

ฐาน: Race Racing 40 (f8eb25cbb410e92f), source d79910e.
เกมใช้งานจริงยังคงรุ่นเดิม ไม่มีการแก้ main หรือ deploy candidate นี้

พบว่าตัวเลือกช่องแซงเป็นเลนตายตัว และ spatial passing path ขยับตาม racing line แทนการถือเลนที่เลือกอยู่ จัดทำ candidate เพิ่มช่องข้างคู่แข่งและถือ road-relative passing lane รวมทั้งปรับการทดสอบเรขาคณิตให้ตรงพฤติกรรมใหม่

ทดลองขยาย gate การบุกและเปิดแผนบุกก่อนเบรกแล้ว แต่รถแยกกลุ่มมากขึ้น จึงถอดการทดลองนั้นออก การถอดโทษ lateral demand 5% ทดลองแล้วก็ยังไม่ทำให้ probe แซงสำเร็จ จึงถอดออกเช่นกัน

58 configured engine checks ผ่านใน candidate F; build และ PWA/service-worker ผ่านใน candidate F แต่ไม่ใช่หลักฐานว่าการแซงผ่าน

เกณฑ์พฤติกรรมยังไม่ผ่าน: Suzuka seed 7 แข่ง 3 รอบยังไม่มีแซงหลังรอบแรก และ probe รถสองคันที่เริ่มบนทางตรง มีความเร็วไล่ 2 m/s ห่าง 22 m ยังแซงจนพ้นไม่สำเร็จ แม้ไม่พบ stop/rejection/ออกขอบใน probe จึงไม่เผยแพร่แพตช์นี้

SUMMARY.json เก็บสรุปการทดลอง รวมข้อจำกัด บางการทดลองหยุดก่อนจบ จึงไม่มีผลเต็ม ห้ามอ้างว่าแก้ครบทุกสนามหรือ Android FPS ผ่าน

ขั้นถัดไป: trace แผนความเร็ว/traffic cap และเหตุผลยกเลิก PASS_COMMIT ทีละ thought ใน probe ที่ไม่ผ่าน แล้วแก้ต้นเหตุ ก่อนรัน seed เดิมครบเรซและตรวจการแซงหลังรอบแรกซ้ำ ห้ามใช้การแซงออกตัวแทนเกณฑ์นี้
