# F1M RACECRAFT 47

Build `6ca6ee76c69b2af3`. ปรับการดวลต่อเนื่องหลังรอบแรก โดยคง driver profiles ของ R46 และไม่สั่งคันนำผ่อนรอหรือเพิ่มกำลังตาม gap/rank

## พฤติกรรมที่เปลี่ยน

- หลัง 30 วินาที รถถือช่องแซงคงที่เทียบกับขอบถนนหลัง smooth join จึงไม่เลื่อนเข้า apex เดียวกับคู่แข่งขณะพยายามแซง ยังคง safeLane และ footprint guard
- ถอนแผนแซงก่อนโค้งเมื่อระยะปิดไม่พอ แล้วกลับไลน์พร้อมพักแผน 2 วินาที ไม่ถอนขณะขึ้นคู่หรือมีรถใกล้ 18 เมตร
- วางแผนเบรกจาก brakingBudget จริงพร้อมสำรอง 20% แทนค่าคงที่ ลดตามแรงยึดเกาะเปียก ช่วงออกตัวก่อน 30 วินาทียังคงรูปแบบช่องแซงเดิม
- ERS AUTO เก็บก่อนทางตรงสั้น/เบรก และใช้เร่งใน wake บนทางตรงยาวเพื่อสร้างความเร็วปิดระยะ ก่อนเบี่ยงจบแซง คำสั่ง SAVE/CONSERVE ของผู้เล่นยังมาก่อน
- เก็บพลังงานเบรกกลับด้วย regen สูงสุด 350kW และสัดส่วนเบรกหลัง 0.75 แทน 100kW/0.25 ลด friction brake ในปริมาณเดียวกัน ไม่เพิ่มแรงเบรกรวม แบตเตอรี่ยัง 8MJ และ deploy สูงสุด 600kW
- เหตุการณ์แซงจริงเปิดโอกาสสวนกลับ และแสดง “แซงคืนสำเร็จ” เมื่อแซงกลับเป้าหมายนั้นจริง
- ลด throttle และปิด ERS เมื่อเกิน 104m/s ก่อนถึง guard 106m/s ป้องกัน overspeed ที่พบช่วงท้าย Suzuka ไม่แก้ velocity หรือยก guard เซฟใช้ขอบเขตความเร็วเดียวกับเรซ และยังปฏิเสธค่าที่เกินขอบเขต

## ขอบเขตการยืนยัน

เรซ Shanghai/Suzuka 4 ชุดเดินต่อจาก V8 state checkpoint ที่ 300 วินาทีหลัง host process ขาดช่วง โดยเก็บ event/timing/agent/guard state เดิม ผลแซงเป็น event history ทั้งเรซ แต่ off-track sampling และ near/side pair-seconds ของไฟล์ resumed ครอบคลุมเฉพาะช่วงหลัง checkpoint จึงไม่ใช้เปรียบเทียบทั้งเรซ ดู CHECKPOINT_COVERAGE.json

Bahrain สองชุดและ launch matrix เก็บจาก candidate ก่อนเพิ่มตัวลดกำลัง เพราะวัดความเร็วทุกก้าวแล้วยังต่ำกว่า 104m/s ซึ่ง wrapper คืน command เดิมทุกประการ ดู LIMITER_NOOP_COVERAGE.json

ไม่รับประกันจำนวนแซงทุก seed โดยเฉพาะ Shanghai42 ยังไม่มีการแซง ชุด Node/batch ไม่ใช่การยืนยัน Android FPS เสียง หรือสัมผัสจริง เซฟ compatibility ตรวจเซฟเริ่มกริดที่สร้างจาก R46 ไม่ครอบคลุมเซฟทุกสถานการณ์
