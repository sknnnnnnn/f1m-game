# F1M Engine 1.0 — แก้กลางคืน / แรงเร่ง / DRS / Pit

อัปเดตจาก commit 2800f10 บน develop/f1m-engine-1.0 สำรองต้นฉบับและประวัติเดิมครบ ไม่มีการแก้ main และยังไม่มี GitHub push สำเร็จ

## สิ่งที่เปลี่ยน

1. กลางคืน: คง SpotLight สี่ช่องใน shader แล้วเปลี่ยนความเข้มแทนเพิ่ม/ลดชุดไฟ เตรียม shader ด้วย compileAsync ตั้งแต่โหลดก่อนเริ่ม race worker; CPU fallback แบ่ง geometry เป็น block เพื่อข้ามเฉพาะสามเหลี่ยมที่อยู่นอก frustum ไม่ลดจำนวนโมเดล ความละเอียดภาพ หรือระยะมองเห็น
2. แยก rendering hitch ออกจาก physics: heartbeat ของภาพยอมให้สะดุดสั้น ๆ ได้ไม่เกิน 2 วินาที แทน 250 ms; ยังพักทันทีเมื่อซ่อนแท็บ/เสียโฟกัส และยังใช้ dt ฟิสิกส์เดิม ไม่ข้าม tick หรือเพิ่มความเร็วปลอม การปรับ guard เพียงอย่างเดียวไม่ใช่หลักฐานว่า FPS ดีขึ้น
3. แรงเร่ง: ERS จาก 120 เป็น 240 kW และแบตเตอรี่จาก 4 เป็น 6 MJ ใช้ตามแรงเกาะจริง ไม่ boost ขณะลื่น/เลี้ยวแรง เปิดใช้หลังทางออกโค้งได้เร็วขึ้น ปรับ feed-forward ไม่ให้ยกคันเร่งก่อนถึงจุดเบรกในโค้งอ่อนมากเกินไป ยังไม่เปลี่ยน frozen solver/controller หรือเขียนความเร็วรถตรง ๆ
4. DRS: สิทธิ์ตามคันหน้าที่จุดตรวจเพิ่มจาก 1 เป็น 10 วินาที คงสิทธิ์สำหรับเขตนั้นและยังปิดเมื่อเบรก เลี้ยวแรง เข้าพิต ธงเหลือง หรือ Safety Car
5. Pit: เลิกเบนเข้าช่องซ่อมล่วงหน้า 85 เมตร รถอยู่เลนกลางจน 20 เมตรก่อนช่องตัวเอง แล้วเลี้ยวด้วยเส้นโค้งต่อเนื่อง 18 เมตร; ควบคุมความเร็วตาม knot ของแนวเลี้ยวจริง รวมทั้ง SC ใช้เลนผ่านแยก ไม่เข้า bay ทีมแข่ง

## ผลทดสอบที่รันจริง

| รายการ | ก่อน | หลัง |
|---|---:|---:|
| 0–100 km/h ทางตรง full throttle | 4.02 s | 4.02 s |
| 0–200 km/h ทางตรง full throttle | 7.43 s | 7.10 s |

0–300 เป็นการทดสอบฟิสิกส์บนทางตรง ไม่ใช่การรับประกันว่ารถจะทำได้ทุกโค้งในสนามจีน ในข้อมูลจีนยังมีช่วงโค้งช้าที่ต่ำกว่า 100 km/h และเกมไม่ได้ล็อกความเร็วไว้ที่ 100

- China และ Suzuka: รถ 6 คันจบหนึ่งรอบ ไม่มี race stop หรือ controller rejection (`MOBILE_DRIVE_AFTER.json`, `MOBILE_DRIVE_SUZUKA.json`)
- เข้า Pit จริงจนหยุด SERVICE ทั้งสองสนาม ระยะคลาดตามยาวประมาณ 0.13 m ด้านข้างประมาณ 0.38–0.39 m
- เข้า Pit พร้อมกัน 6 คัน: หยุดครบทุกช่อง ไม่มีรุกพื้นที่ทำงานช่องอื่น ขนาดทดสอบช่อง ±6 m ตามยาว / ±3 m ด้านข้าง; ตรวจมุมตัวรถจริง 282,960 จุดใน China และ 299,760 จุดใน Suzuka ไม่รวมโต๊ะ/คนทุกชิ้นในฉาก (`PIT_BAYS_*.json`)
- SC ครบวงจร PARKED → DEPLOY → LEAD → IN_LAP → RETURN → PARKED กลับ GREEN ไม่มี controller/SC rejection (`MOBILE_SAFETY.json`)
- DRS ทดสอบ 0.5 / 5 / 10 วินาที เปิดได้, 10.01 ไม่ได้ และเงื่อนไขปิดเดิมผ่าน
- กลางคืนทดสอบ scene graph สลับโหมดซ้ำ ไฟคง 4 ดวง ความเข้ม 0/1400 ไม่มีการเปลี่ยน resolution หรือ render distance
- CPU raster เทียบ RGBA ทุก pixel กับ renderer ก่อนแก้ที่ 4 กล้องและหลังแก้ตำแหน่ง geometry ตรงกันทั้งหมด; ตัวอย่าง geometry 4,800 vertices คำนวณเพียง 192–384 vertices ที่อาจเห็นได้ (`CPU_VISIBILITY.json`)
- npm test, build และ test:pwa ผ่าน; frozen files/models 20 ไฟล์ SHA เดิมคงอยู่

Browser รุ่น fe75225a2ce12aa3 สลับกลางคืนและวัดผล 5 วินาทีได้ ไม่มี error กลางวัน 1.796 FPS / กลางคืน 1.795 FPS ใน CPU fallback buffer 150 × 300 เท่าเดิม ยังไม่พบ FPS เพิ่มขึ้นใน remote browser นี้ (`MOBILE_BROWSER_*.json`)

## ขอบเขตที่ยังไม่ยืนยัน

เครื่องทดสอบ browser เป็น remote Chrome CPU fallback ไม่มี WebGL จึงยังยืนยัน Android GPU FPS, shader stall ของเครื่องผู้ใช้ หรือความร้อนเมื่อเล่นนานไม่ได้ ไม่มีการอ้างว่าได้ 30/60 FPS บน Android; การติดตั้ง PWA จริงและ PIT release/merge เต็มวงจรทุกสถานการณ์ยังต้องทดสอบเพิ่ม

Preview เดิมจะได้รับ build ใหม่ผ่าน Settings → ตรวจอัปเดต → อัปเดตพร้อมแล้ว ขณะพักการแข่งขัน
