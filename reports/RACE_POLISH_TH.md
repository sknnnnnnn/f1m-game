## การขับและภาพ

- ลด roll/pitch ของตัวถังประมาณ 70%, เพิ่ม damping เพื่อลดเด้งกลับ, ลด heave สูงสุด 45→16 มม. การยึดเกาะและแรงเครื่องไม่เปลี่ยน
- ลด lens/aim/roll ของกล้อง เพิ่มมองเข้าโค้งใน FPS/nose อย่างนุ่มนวล ไม่เกิน 4 องศา, มีตัวเตือนรถหลัง/ด้านข้างตามตำแหน่งจริงพร้อมตรวจระดับสะพาน และกระจกหลัง 3D เปิดเลือกได้ในเมนูกล้อง
- แทรกเวลา มุมพวงมาลัย อัตราเร่ง และเฟสล้อระหว่าง snapshot จริง ทำให้ภาพต่อเนื่องที่ 60 Hz โดยไม่ทำนาย/แก้สถานะฟิสิกส์
- คงไลน์แซงที่กำลังทำอยู่ก่อนเปลี่ยนเป็นแผนเบรกดวลโค้ง และลดความต่างการผ่อนกำลังจากสไตล์ถนอมยางเล็กน้อย คงบุคลิก ความเสี่ยง และกติกาพื้นที่เดิม

## เสียง

- ปรับฮาร์โมนิก/ฟิลเตอร์เครื่องให้คมน้อยลง ลดเสียงกระแทกเปลี่ยนเกียร์และลม เพิ่มเสียงรถใกล้ได้สองคันพร้อมสเตอริโอและ Doppler
- วิทยุพูดด้วยเสียงของเครื่อง เลือกเสียงไทยที่พร้อมก่อน แล้วใช้เสียงอังกฤษสรุปเหตุการณ์เมื่อไม่มีไทย ปุ่มเปิด/ปิด/ลองเสียงอยู่ในเมนูกล้อง
- ใช้ข้อความเหตุการณ์จริง กรองซ้ำ ไม่สะสมคิว ข้อความสำคัญแทรกได้ ยกเลิกเมื่อพัก/เปลี่ยนรถ/รีเพลย์/ซ่อนแท็บ ลดเสียงเกมระหว่างพูด
- การฟังจริงและเสียงไทยขึ้นอยู่กับเสียงที่ติดตั้งในอุปกรณ์ เสียงเครื่องยังเป็น procedural synthesis ไม่ใช่ไฟล์เสียง F1 ลิขสิทธิ์

กระจกหลัง 3D เริ่มต้นปิดเพื่อเน้น FPS: กล้องหลังอัปเดตไม่เกิน 10Hz, ใช้ render target ของตนเอง, คืน viewport/scissor/render target/เงา/การแสดงรถหลักครบทุกครั้ง หากกระจกทำงานผิดพลาดจะปิดกระจกและให้เกมหลักทำงานต่อ ทดสอบ state restoration และ failure path ด้วย renderer fixture; ยังไม่ได้ตรวจภาพ WebGL/ต้นทุน GPU บน Android

## เป้าหมาย 60 FPS

- จัดจังหวะวาด 60 Hz บนจอความถี่สูง, physics worker cadence คงเดิม, heartbeat ลดข้อความที่ไม่จำเป็น
- แคช IK ของช่างเมื่อท่าร่างกาย/เท้า/มือ/สิ่งกีดขวางไม่เปลี่ยน แต่ขยับศีรษะต่อทุกเฟรม อัปโหลด instance matrix เฉพาะส่วนที่เปลี่ยน
- ช่างพิตใช้ขอบเขตคัดกรองที่ครอบคลุมเส้นทาง deploy/service/return ทุกท่า จึงข้ามการวาดนอก frustum ได้ โดยยังเก็บรูปทรงทุกชิ้น
- ใช้ข้อมูลฉาก/เวกเตอร์ซ้ำ ลดการหา road pose และ object allocation ซ้ำ ไม่ลด DPR เงา texture polygon หรือระยะมอง
- ตัวเลข FPS มาจากเฟรมที่วาดจริง ไม่ใช่ตัวเลขเป้าหมาย มีปุ่ม **ตั้งค่า → วัด 60 FPS · 30 วินาที** สำหรับวัดระหว่างแข่งจริง หยุดวัดถ้าเกมพัก

ตัวอย่างรายงานมือถือเก่าใช้ระบุคอขวด: frame work median 23.7 ms, render 13.9 ms, pit crew 7.2 ms เป็นคนละ build กับรุ่นนี้ จึงใช้ยืนยัน FPS หลังแก้ไม่ได้

## หลักฐาน

- ชุดหลัก 47 งานผ่าน, build/PWA ผ่าน
- เทียบ instance matrix 106,560 ค่า กับ rig เดิม, tolerance 1e-6 และ invalidation เมื่อเคลื่อน/เปลี่ยนสิ่งกีดขวาง/ซ่อน
- CPU microbenchmark งานท่ายืนนิ่ง: 40.43→7.79 ms รวม 120 เฟรม×22 คน; เร็วขึ้น 5.19 เท่าใน Node ไม่ใช่ Android FPS
- ตรวจขอบเขตช่าง 51,282 ครั้งจาก GLB จริงและสามช่วง deploy/service/return ไม่มีส่วนที่ถูกตัดนอก bound
- กล้องผ่าน 16 scenarios (portrait/landscape, 30/60/90/120Hz, worker packets 45/70ms)
- แข่ง 3 รอบ×6 คัน×3 สนาม ก่อน/หลัง: ทุกคันจบ ไม่มี off-road/retire/contact stop/rejected plan
