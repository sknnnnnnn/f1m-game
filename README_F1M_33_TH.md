# F1M China & Suzuka / 33

เปิด `F1M_China_Suzuka_33.html` ด้วย Chrome ได้เหมือนรุ่นเดิม ไฟล์รวมเกมและโมเดลไว้ในตัว ไม่ต้องติดตั้งแพ็กเกจเพื่อเล่น

- เปิดครั้งแรกเป็น China / Shanghai
- เปลี่ยนสนาม: **ตั้งค่า → สนาม / Championship → เลือกสนาม → ลองสนามนี้**
- มี China / Shanghai, Japan / Suzuka และสนามเดิม Bahrain, Canal Park, Ridge
- โหมดรายการเก็บลำดับสนามเดิมสามสนาม แล้วเพิ่ม Shanghai กับ Suzuka เป็นสนามที่ 4–5
- Shanghai แข่ง 5 รอบ / Suzuka 4 รอบ หากเลือกจำนวนรอบตามสนาม
- ปุ่มเริ่มแข่งจะให้ช่างถอนมือ ลุก หัน และเดินพ้นถนนก่อนเริ่มไฟสตาร์ต

## เปลี่ยนในรุ่นนี้

ใช้ซอร์ส `SHANGHAI_SCENE_02.mjs` และ `SUZUKA_SCENE_02.mjs` ชุด Presentation 02 ที่ออกแบบไว้เดิม: รูปสนาม อาคาร อัฒจันทร์ ภูมิทัศน์ ธง ผู้ชม และชิงช้าสวรรค์ของ Suzuka อยู่ในเกมหลัก พร้อมเชื่อม AI, กริด, พิต, ยาง, DRS, กล้อง และ minimap

ใช้แสงกลางวันเมื่อเข้าสนามใหม่ เปลี่ยนกลางวัน/กลางคืนในตั้งค่าได้เช่นเดิม จัดอาคารชั้นบนให้ทำงานร่วมกับโรงรถ Pit Flow โดยไม่วางโรงรถซ้อนกัน รวมชิ้นส่วนฉากคงที่ตามวัสดุ/ตำแหน่งโดยเก็บรูปทรงเดิม ไม่ลดความละเอียดหรือระยะมองเพื่อเพิ่มความลื่น

Suzuka แสดงระดับพื้นและสะพานตามแบบเดิม รถและกล้องตามระดับถนน การหาตำแหน่งใช้ทิศรถช่วยแยกทางไขว้ รถบนสะพานกับรถด้านล่างไม่ชนกัน แต่รถบนถนนระดับเดียวกันยังตรวจชนตามเดิม

ช่างบนกริด 18 คน / 3 คนต่อรถ: ตรวจยางหน้า ตรวจยางหลัง และวิศวกรถือแท็บเล็ตหันเข้าหารถ ใช้จุดเป้าหมายมือร่วมกับเครื่องมือ สีชุดตามทีม และติดตามตำแหน่งรถจริงแม้ลำดับกริดเปลี่ยน

## ตรวจแล้ว

- จำลองครบหนึ่งรอบทั้งสองสนาม รถทั้ง 6 คันเข้าเส้นชัย ไม่มีรถถอนตัว ไม่มี CONTACT_GUARD และไม่มี controller rejection ในชุดทดสอบ seed 7
- Shanghai ใช้เวลาจำลองจนรถครบ 200.63 วินาที / Suzuka 207.60 วินาที
- ทดสอบรถหนึ่งคันเข้าพิตจนหยุด SERVICE ทั้งสองสนาม: คลาดตามยาวประมาณ 12 / 15 ซม. ไม่มี controller rejection
- ทดสอบสะพานต่างระดับยังปลอดการชน และรถซ้อนบนชั้นเดียวกันยังตรวจพบ
- ทดสอบมือช่าง 18 คน ระยะเอื้อมไม่เกินแขนจริง และเดินพ้นสนามก่อน LIGHTS รวมกรณีกริดสลับลำดับ
- เปิดภาพ WebGL ทั้งสองสนามและตรวจภาพกริดแล้ว ไม่พบ JavaScript error ขณะโหลด

## ขอบเขตผลทดสอบ

ผลจำลองหนึ่งรอบไม่ได้รับรองทุก seed, ทุกสถานการณ์แซง หรือการแข่งขันหลายรอบ ระบบ CONTACT_GUARD เดิมยังทำงาน

ยังไม่ได้วัด FPS บนมือถือของผู้ใช้ ในสภาพทดสอบที่ใช้ software WebGL การเริ่มเล่นแบบภาพ 3D อาจถูก guard พักเมื่อเฟรมเกิน 250 ms ซึ่งยังคงเปิดไว้ รุ่นนี้ไม่ได้อ้างว่าแก้ความกระตุกทั้งหมดแล้ว

ความสูงของ Suzuka เป็นข้อมูลที่ผู้สร้างออกแบบ ไม่ใช่ข้อมูลสำรวจสนามจริง ระบบขับเคลื่อนหลักยังเป็น frozen planar solver เดิม ไม่ได้เพิ่มแรงโน้มถ่วง/โหลดช่วงล่างตามเนิน การแยกชั้นสะพานเป็นการตรวจเรขาคณิตเพิ่มเติม

ทดสอบพิตข้างต้นตรวจทางเข้าและหยุดในช่อง SERVICE ยังไม่ใช่การยืนยันครบวงจรช่างเปลี่ยนยาง–ปล่อยรถ–รวมกลับครบทุกคัน

## ซอร์สและการกู้คืน

`F1M_33_Recovery_Checkpoint.json` เก็บซอร์ส โมเดล และหลักฐาน JSON พร้อม SHA-256 ของแต่ละไฟล์ ไม่มี ZIP

กู้คืนด้วย Python 3: ใช้สคริปต์ `RESTORE_33.py` ใน checkpoint หรืออ่านไฟล์ JSON แล้วเขียนแต่ละรายการตาม encoding (`utf8` / `base64`) ตรวจ SHA-256 ให้ตรงก่อนเขียน

สำหรับพัฒนา: `npm ci` แล้ว `npm run build` จะได้ HTML เดี่ยวและ `dist/index.html` ต้องใช้ Node.js เฉพาะตอนพัฒนา/ประกอบ ไม่ต้องใช้ตอนเล่น
